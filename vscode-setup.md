# VS Code Setup

## Extensions I Installed

1. Live Server - to run my site live and see changes quickly
2. Prettier - to format my code clean
3. Auto Rename Tag - when I change one tag, other one changes auto
4. HTML CSS Support - gives color and autocomplete for CSS
5. GitHub Pull Requests - to manage my repo easy

## Why these?
These help me write HTML faster and keep code neat. Live Server is most useful for me because I can see my portfolio directly.
